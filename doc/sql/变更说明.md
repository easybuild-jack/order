# order_info 表结构调整说明

## 概述
本次调整以 `OrderInfo.java` 实体类为准，对 MySQL 和 PostgreSQL 的 `order_info` 表结构进行修正，确保数据库表结构与实体类完全一致。

## 变更详情

### 🔴 新增字段（实体类有但SQL脚本缺失）

| 字段名 | 类型 | 长度 | 说明 |
|--------|------|------|------|
| `user_name` | VARCHAR | 100 | 用户名称 |
| `store_id` | VARCHAR | 50 | 存货点ID,可以是货柜ID，提货点ID |
| `store_name` | VARCHAR | 100 | 存货点名称 |

### 🟡 字段类型修正

| 字段名 | 原类型 | 修正后类型 | 说明 |
|--------|--------|------------|------|
| `order_channel` | INT(50) / INTEGER | VARCHAR(50) | 订单渠道应为字符串类型 |
| `client_type` | INT(2) / SMALLINT | VARCHAR(50) | 客户端类型应为字符串类型 |

### 🟢 字段长度优化

为了更好地支持业务需求，对部分字段的长度进行了扩充：

| 字段名 | 原长度 | 新长度 | 说明 |
|--------|--------|--------|------|
| `goods_name` | 50 | 150 | 商品名称长度扩充 |
| `goods_sku_name` | 150 | 200 | SKU名称长度扩充 |
| `goods_pic` | 200 | 500 | 图片URL长度扩充 |
| `user_remark` | 200 | 500 | 买家备注长度扩充 |
| `tag_remark` | 200 | 500 | 标记备注长度扩充 |
| `merchant_remark` | 200 | 500 | 商家备注长度扩充 |
| `order_remark` | 200 | 500 | 订单备注长度扩充 |
| `cancel_remark` | 200 | 500 | 取消原因备注长度扩充 |

### 🟣 数值精度提升

为支持更大金额的业务场景，提升金额字段精度：

| 字段名 | 原精度 | 新精度 | 说明 |
|--------|--------|--------|------|
| `total_amount` | DECIMAL(10,2) | DECIMAL(12,2) | 总金额精度提升 |
| `actual_pay_amount` | DECIMAL(10,2) | DECIMAL(12,2) | 实际支付金额精度提升 |
| `refund_amount` | DECIMAL(10,2) | DECIMAL(12,2) | 退款金额精度提升 |

## 文件列表

## 部署建议

### 方案一：新建表（推荐用于新环境）
直接执行修正后的SQL脚本创建新表。

### 方案二：增量更新（适用于生产环境）
```sql
-- MySQL 增量更新语句
ALTER TABLE order_info 
ADD COLUMN user_name VARCHAR(100) DEFAULT NULL COMMENT '用户名称',
ADD COLUMN store_id VARCHAR(50) DEFAULT NULL COMMENT '存货点ID,可以是货柜ID，提货点ID',
ADD COLUMN store_name VARCHAR(100) DEFAULT NULL COMMENT '存货点名称',
MODIFY COLUMN order_channel VARCHAR(50) DEFAULT NULL COMMENT '订单渠道',
MODIFY COLUMN client_type VARCHAR(50) DEFAULT NULL COMMENT '客户端类型';

-- PostgreSQL 增量更新语句
ALTER TABLE order_info 
ADD COLUMN user_name VARCHAR(100) DEFAULT NULL,
ADD COLUMN store_id VARCHAR(50) DEFAULT NULL,
ADD COLUMN store_name VARCHAR(100) DEFAULT NULL,
ALTER COLUMN order_channel TYPE VARCHAR(50),
ALTER COLUMN client_type TYPE VARCHAR(50);

COMMENT ON COLUMN order_info.user_name IS '用户名称';
COMMENT ON COLUMN order_info.store_id IS '存货点ID,可以是货柜ID，提货点ID';
COMMENT ON COLUMN order_info.store_name IS '存货点名称';
```

## 注意事项

1. **数据备份**：在生产环境执行前，请务必备份现有数据
2. **兼容性**：新增字段均为可空字段，不影响现有数据
3. **应用验证**：部署后需验证相关功能是否正常
4. **索引重建**：如涉及字段长度变化，可能需要重建相关索引

## 验证方法

执行以下SQL验证表结构是否正确：

```sql
-- MySQL
DESCRIBE order_info;

-- PostgreSQL  
\d order_info
```

检查新增字段是否存在，字段类型和长度是否正确。
